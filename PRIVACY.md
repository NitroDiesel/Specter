# Privacy Policy

Effective date: July 16, 2026

Specter does not collect, transmit, sell, or share personal data.

## Data stored on the device

Specter uses browser extension storage for:

- protection settings and appearance preferences;
- site exception patterns and expiration times;
- temporary per-tab override state;
- optional activity logs and aggregated site activity;
- the most recent diagnostic error.

Activity logging is disabled by default. When enabled, logs can contain the page origin (for example, `https://example.com`), event category, timestamp, and event-specific counters. Specter does not retain URL paths, query parameters, fragments, form values, or page content in its logs. Logs are capped and remain in local extension storage unless the user explicitly exports them.

## Network activity

Specter has no analytics, advertising, account system, telemetry endpoint, or remote configuration service. All interface assets are bundled with the extension. Links to the project repository open only when the user selects them.

## Website access

Specter requests access to supported web pages so it can inject its visibility and focus controls. It does not read page content for advertising, profiling, or remote transmission.

## User control

Users can disable protection globally, disable it for a tab, create or remove site exceptions, turn logging off, clear stored logs and site activity, or remove all extension data by uninstalling Specter.

## Changes

Material changes to this policy will be documented in the repository changelog and included with a new extension release.

## Contact

Questions can be opened in the public issue tracker. Security-sensitive reports should follow [SECURITY.md](SECURITY.md).
